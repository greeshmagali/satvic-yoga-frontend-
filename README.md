# Satvic Yoga Frontend Clone

A responsive frontend clone of the Satvic Yoga website, built to practice real-world UI development and strengthen frontend design skills.
This project focuses on creating clean layouts, responsive design, and maintaining visual consistency across the application.

---

## 🚀 Technologies Used

* **HTML5** – Structuring the web pages
* **CSS3** – Styling, layouts, and responsiveness
* **JavaScript** – Adding basic interactivity

---

## ✨ Features

* Clean and modern UI inspired by Satvic Yoga
* Responsive design for desktop screens
* Well-structured sections for better readability
* Smooth navigation and organized layout flow
* Reusable and maintainable code structure

---

## 🛠️ Development Process

1. Analyzed the original Satvic Yoga website layout
2. Planned the structure and UI sections
3. Built the layout using semantic HTML
4. Styled the project with CSS using responsive design principles
5. Added JavaScript for basic interactivity
6. Tested the layout across different screen sizes
