#  Satvic Yoga Frontend Clone

A responsive frontend clone of the **Satvic Yoga** website, created to practice real-world UI development and improve frontend design skills.  
This project focuses on clean layouts, responsiveness, and visual consistency.

---

##  Technologies Used

- **HTML5** – For structuring the web pages  
- **CSS3** – For styling, layout, and responsiveness  
- **JavaScript** – For basic interactivity  

---

##  Features

- Clean and modern UI inspired by Satvic Yoga  
- Fully responsive design ( desktop)  
- Structured sections for better readability  
- Smooth navigation and layout flow  
- Reusable and organized code structure  

---

##  Process

1. Analyzed the original Satvic Yoga website layout  
2. Planned the structure and sections of the UI  
3. Built the layout using semantic HTML  
4. Styled the application using CSS with responsive design principles  
5. Added JavaScript for basic interactivity  
6. Tested the layout across different screen sizes
